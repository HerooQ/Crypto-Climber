Crypto Climb · about 45–60 minutes

Start simple. Get cryptographic.

Short puzzles that ramp up gradually. You begin with a Caesar cipher where the shift is handed to you, then move through Atbash, Vigenère, XOR, hidden keys, hashing and finally AES-GCM. Whenever a shift or key is meant to be known, it is shown on screen. It is only withheld on the puzzles that ask you to recover it.

How generation works

      

        Each puzzle fetches fresh English words from a public random-word API and then performs the
        cipher operation in your browser. Your submitted answers are never sent to that API. If the
        API is unavailable, a built-in word list is used instead.
      

      

        Attempts live only in this page's JavaScript memory. There is no database, account,
        analytics, or score server.
